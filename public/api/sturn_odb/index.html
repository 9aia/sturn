Crate sturn_odb 

Source
Expand description

Direct git ODB access — loose-object write/read, ref resolution, tree lookup — so hot paths (wal.append, ws.store, ws.read) skip git process spawns entirely.

Scope is deliberately narrow: loose objects and refs only. Anything the fast path can’t see — packed objects, alternates, unusual revs, corrupt files — reports None/errs and the caller falls back to plumbing, so on-disk semantics stay identical to spawning git.
