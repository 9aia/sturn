Config — sturn.toml ​

Top level ​

fieldtyperequirednotes
repoRepoCfgrequiredThe coordinated repo.
walWalCfgoptional—
busBusCfgoptional—
actorActorCfgoptional—
signingSigningCfgoptional—
reviewReviewCfgoptional—
hooksHooksCfgoptional—

[repo] ​

fieldtyperequirednotes
dirpathrequiredRepo dir (the ODB lives at &lt;dir&gt;/.git).
idstringoptionalTopic prefix id, e.g. "9aia/sturn". Defaults to dir basename.
branchstringoptionalBranch snap updates by default.

[wal] ​

fieldtyperequirednotes
ref_prefixstringoptionalWAL ref prefix — one ref per workspace beneath it.

[bus] ​

fieldtyperequirednotes
storepathoptionalEmbedded store path for the local bus impl.
poll_msintoptionalDaemon poll interval for WAL→topic fan-out, ms.
reposlistoptionalExtra repo dirs this daemon also fans out — multi-repo from one process. Topic ids derive from dir basename.

[actor] ​

fieldtyperequirednotes
namestringoptionalActor name. Defaults to $STURN_ACTOR, then $USER.

[signing] ​

fieldtyperequirednotes
keystringoptionalPrivate key path (ed25519). ~ expands.
allowed_signersstringoptionalallowed_signers for sturn verify.

[review] ​

fieldtyperequirednotes
requirebooloptionalEvery Write/Rename/Delete since last snap must hold an Approve review (in any ws's WAL) before snap lands.

[hooks] ​

fieldtyperequirednotes
post_oplistoptionalShell commands spawned (sh -c, detached, cwd = repo dir) after a successful ref-moving verb — claim, leave, write, snap, push, … The event-driven way to re-index: e.g. post_op = "kuda sync" replaces kuda watch --poll-refs when sturn drives the writes. One string or a list; $STURN_POST_OP (single command) overrides.

Constraints ​

  • Search order: --config <path> → $STURN_CONFIG → ./sturn.toml → ~/.config/sturn/sturn.toml.
  • Every table has deny_unknown_fields — typos fail the load.
  • Secrets never live here; secret material resolves through the Secrets chain (sturn-secret → keyring/dotenv).
  • [hooks] post_op also reads $STURN_POST_OP (single command overrides the configured list).
