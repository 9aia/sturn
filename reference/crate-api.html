cratelayerpurpose
sturn-askdomainpending-response asks: fold ops into open questions and verdicts
sturn-claimdomainadvisory claims: fold ops into live locks, detect overlap
sturn-coredomaindomain types: op/event schema, sturn.toml config
sturn-busportBus port: topic pub/sub over the WAL (a cache, not authority)
sturn-secretportSecrets port: named-secret resolution
sturn-serviceportService port: OS service lifecycle
sturn-walportWal port: append-only op log inside git refs
sturn-wsportWs port: virtual workspaces over the git ODB
sturn-bus-redbadapterBus impl: redb-backed topic store with cursors
sturn-configadapterConfigSource port + scarab-config-file impl: sturn.{yaml,yml,toml} discovery
sturn-dotenvadapterSecrets impl: KEY=VAL file, chmod 600
sturn-fuseadapterFUSE impl: mount a ws tree read-only for POSIX tools
sturn-gitadapterVcs impl via the git binary + WAL->commit snap
sturn-keyringadapterSecrets impl: secret-tool (libsecret)
sturn-odbadapterDirect git ODB access: loose objects, refs, trees — no process spawns
sturn-systemdadapterService impl + deploy helpers: systemd user units
sturn-wal-gitadapterWal impl: ops as commits on refs/sturn/wal/* via git plumbing
sturn-ws-gitadapterWs impl: read/list/materialize via git plumbing
sturnenginesturn — ephemeral coordination engine: claims/ops/topics over VCS state (engine lib + compat bin)
sturn-driverdrivertamias-driver-sturn — pavo view driver over a repo's sturn coordination state plus engine ops dispatching to the sturn lib
