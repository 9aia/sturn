Ops ​

The event vocabulary appended to refs/sturn/wal/<ws>. JSON, content-addressed (blob sha = event id), one commit per append.

Tree ops ​

OpFieldsEffect at snap
writepath, blob, intent?replace/create file
renamefrom, tomove entry
deletepathremove entry

Coordination ops ​

OpFieldsEffect
claimglob, ttl_secsadvisory lock; auto-expires
releaseglobdrop a claim
intenttextprovenance — why the work exists
reviewevent, verdictapprove/reject an event id
snapshotmessagemarker — ops before it are committed
presencestatusactor joined/left
asksubject, target, options?, ttl_secspending response — open question; the event id is the ask handle
answerask, verdictclose an ask with a verdict
cancelaskwithdraw an open ask

Asks ​

Claims are pending ownership; asks are pending answers. An ask opens under its event id and stays open until an answer or cancel op lands — or ttl_secs runs out (0 = never). The question and its answer can live on different workspaces' WALs; responders filter target (actor:<n>, human:<n>, node:<h>, claim-holder:<glob>, any) to find asks meant for them.
