pub fn gui_domain() -> Result<String, Error>
Expand description

The gui/<uid> launchd domain for the current user — $UID when set and numeric, else id -u (unix only). Needed for every service-target arg (gui/<uid>/<label>).

§Errors

Error::Failed when no uid can be determined (non-unix without $UID — unreachable in practice: launchd verbs only run on macOS).
