hypha-kv — the node-local key/value store port (org proposal P-006). Generic {ns}/{key} addressing over arbitrary JSON values: the substrate half of what used to be sepia-meta’s config/projects sections and peregrin’s /api/config, /api/projects, /api/client/keypair routes.

Values are opaque serde_json::Values — the store never interprets them. What a namespace means (config, project, ui, …) is the integration’s business; the port only carries the {ns}/{key} shape plus a per-namespace Visibility the HTTP surface enforces (internal namespaces never leave the node over /api/kv*).

Secrets policy (org convention): the KV stores secret names and references, never secret values — anything sensitive belongs to cuora. Visibility is a wire filter, not an access control: callers holding the KvStore directly read internal namespaces freely.
