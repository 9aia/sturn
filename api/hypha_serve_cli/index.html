hypha-serve-cli — the one-shot front door for ndjson *-serve binaries (P-020). Every serve binary’s main.rs is the same three lines: no args → service loop; args → one_shot maps <op> [--dir D] [--set k=v]… [--yes|--dry-run] [--range R] onto the serve’s request type and prints the response JSON.

Deliberately dumb: ops stay JSON data, params ride --set k=v — no per-op clap flags. Rich UX belongs to pavo views and the product CLI, not here.

ⓘ
fn main() {
    let args: Vec<String> = std::env::args().skip(1).collect();
    if args.is_empty() { std::process::exit(my_serve::serve()); }
    std::process::exit(hypha_serve_cli::one_shot(&args, |op, params| {
        my_serve::dispatch(&GitVcs, &Request { op: op.into(), params })
    }));
}

Run a one-shot: parse args, dispatch via f(op, params), print f’s JSON result, exit 0 on success / 1 on failure / 2 on usage errors. f returns the response value to print — serve binaries pass their dispatch result serialized.
