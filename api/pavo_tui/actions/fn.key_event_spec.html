pub fn key_event_spec(code: KeyCode, mods: KeyModifiers) -> Option<String>
Expand description

Map a crossterm key event to the pavo_core::KeySpec string the binding table matches — None for events no spec can name.

Rules:

  • Char(c) with no ctrl/alt/cmd modifier → the bare char (case preserved — "D" ≠ "d"); SPACE/+ map to the named specs "space"/"plus". Shift alone doesn’t add a modifier — the shifted char is the spec (P binds as "P").
  • Char(c) with ctrl/alt/cmd → "ctrl+alt+…+c" (shift is ignored — ctrl+shift+p isn’t representable; bind "ctrl+p").
  • Named keys → their canonical lowercase spec (enter, esc, tab, backspace, delete, insert, home, end, pageup, pagedown, up, down, left, right, f1–f12); BackTab → "shift+tab".
