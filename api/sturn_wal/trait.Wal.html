Expand description

Append/read the per-workspace op log — one log per workspace, serialized per workspace, parallel across them (git impl: commits on refs/sturn/wal/<ws>). Replicates with ordinary push/fetch — the bus on top is a cache, never the authority.

Source

fn append(&self, repo: &Path, ws: &str, ev: &Event) -> Result<String>

Append ev to the ws WAL; returns the assigned event id. Must be linearizable under concurrent appends — mechanism is impl-defined (git: CAS retry on the ref).

Source

fn events_since( &self, repo: &Path, ws: &str, from: Option<&str>, ) -> Result<Vec<Event>>

Events appended after from (an opaque cursor returned by head, exclusive) — None reads the whole log. Delta reads are what the daemon and catch-up need; events is the full replay.

Source

fn head(&self, repo: &Path, ws: &str) -> Result<Option<String>>

Opaque tip cursor for the ws log — cheap change detection. Callers must not interpret the value; feed it back to events_since.

Source

fn workspaces(&self, repo: &Path) -> Result<Vec<String>>

Workspace ids that have a log.

Source

fn compact(&self, repo: &Path, ws: &str) -> Result<usize>

Drop pre-snapshot history: events before the last Snapshot are already in the tip — replaying them is waste. Returns events dropped. Old history moves to an archive namespace (git impl: refs/sturn/archive/<ws>) — compaction loses nothing.
