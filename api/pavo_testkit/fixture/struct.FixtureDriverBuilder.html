pub fn new(name: &str) -> Self

A builder for driver kind <name>.

pub fn manifest(self, manifest: DriverManifest) -> Self

Set the manifest — used for both the manifest verb (discovery probe) and the manifest wire op. When unset, a minimal pavo-advertising manifest is generated from name + views.

Source

pub fn view(self, spec: ViewSpec) -> Self

Add a ViewSpec the driver serves via view/views. Its queries bindings are auto-fed from Self::query / Self::query_error payloads.

Source

pub fn query(self, name: &str, data: Value) -> Self

Set the canned data payload for query/binding name — returned by {"op":"query","query":name} and placed in view results’ data map under the binding name.

Source

pub fn query_error(self, name: &str, message: &str) -> Self

Make query/binding name degrade: query ops get ok:false and view data carries {"error": msg} for the binding.

Source

pub fn view_error(self, view_id: &str, message: &str) -> Self

Make view for view_id answer ok:false with message.

Source

pub fn renderers(self, decls: Vec<RendererDecl>) -> Self

Declare renderer plugins in the generated manifest — the manifest renderers list. The render op itself isn’t canned; pair this with Self::transcript for render-op fixtures.

Source

pub fn action(self, action: Action) -> Self

Declare an Action — merged into the generated manifest’s actions[] and used by the invoke op’s default dispatch (required-param checks, echo result). With a custom Self::manifest the actions still feed invoke param metadata but aren’t added to the manifest — declare them there yourself.

Source

pub fn invoke(self, action_id: &str, result: Value) -> Self

Canned invoke result for action_id — result is answered verbatim as the ok:true payload (an ActionResult-shaped object: message/errors/data/view/route/extra). Overrides the default dispatch for that action; undeclared actions configured here still answer (fixture flexibility).

Source

pub fn invoke_error(self, action_id: &str, message: &str) -> Self

Make invoke for action_id answer ok:false with message — the driver-rejection path.

Source

pub fn failure(self, failure: Failure) -> Self

Replace the failure-mode configuration.

Source

pub fn transcript(self, transcript: Transcript) -> Self

Replay mode: answer every serve request from a recorded Transcript instead of the manifest/views/queries config. Unmatched requests get ok:false.

Source

pub fn build(self) -> Result<FixtureDriver>

Write tamias-driver-<name> + its .fixture.json config into a fresh tempdir and return the FixtureDriver.

§Errors

io::Error if the tempdir or files can’t be written, or the executable bit can’t be set (non-unix).
