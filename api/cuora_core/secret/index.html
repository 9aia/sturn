The Secret newtype — a plaintext value that redacts itself.

Debug/Display print Secret(***)/***, never the value; the only way out is the explicit .expose() call, which greps loud in review. No serde impls — serialization of a value (e.g. the vault payload) goes through .expose() at the edge, deliberately. The inner string is [zeroize::Zeroizing] so drops scrub the buffer.
