GET /api/entities — the node’s entity index: one {id,kind,indexDoc,updatedAt,locked,live} doc per resident entity. with_locks adds the withLocks=1 lock-probe fields.

GET /api/entities/{id} — one entity doc. Kind-registered entities get their policy’s scope params (?agent=… remains the interim disambiguator on sepia-session).

§Errors

POST /api/entities/{id}/ops — submit {kind, payload}; the node dispatches namespaced ops (sepia.* → the session plane, entity.* → substrate verbs).

pub fn send_json( &self, method: &str, path: &str, body: &Value, ) -> Result<Value, NodeError>

{method} {path} with a JSON body — raw JSON body back. For non-session-scoped writes (/api/projects, /api/config/{k}, /api/push/subscribe); DELETE may carry a body.

§Errors

Source

pub fn events(&self) -> Result<EventStream<BodyReader<'static>>, NodeError>

GET /api/events — the node-level feed. The returned reader yields FeedEvents until EOF or the feed stays silent past sse_idle_timeout (then next_event errors and the caller reconnects).

§Errors

On connect failure or a non-2xx status.

Source

pub fn entity_stream( &self, id: &str, kind: Option<&str>, ) -> Result<EventStream<BodyReader<'static>>, NodeError>

An entity’s live event stream (plus lagged markers). The path and scope params come from the kind’s registered crate::KindPolicy — /api/sessions/{id}/stream?agent=… today; /api/entities/{id}/events once entity events exist node-side. Same SSE reader as Self::events.

§Errors

On connect failure, a non-2xx status, or a kind with no registered stream policy.
