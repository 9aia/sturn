myco done list|remove — the DONE.md archive read + delete. Archived tasks (done and cancelled) leave TODO.md but stay here, filterable like every other list; remove drops a subtree from the archive entirely — for scaffold junk and mistakes, since reopen (item set --status open) is the verb for work that isn’t actually finished.
