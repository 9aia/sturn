Watch

Watch the repo — fs events trigger incremental syncs (debounced; only changed modules re-summarize). Domain corpus roots are watched explicitly, so record writes (myco verbs, doc edits) re-index like code writes.

Fields

§poll_refs: Option<u64>

Also poll non-tree domain sources every N seconds. Git refs (refs/sturn/*) produce no fs events a watcher can use — a moved/new/deleted ref fingerprint triggers the same debounced sync.
