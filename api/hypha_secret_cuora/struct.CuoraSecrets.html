Struct CuoraSecrets 

Source 
pub struct CuoraSecrets { /* private fields */ }
Expand description

Secrets over cuora — CLI or cuora serve transport per CuoraTransport. Generic over the ref scope (the cuora://<scope>/… namespace) and the audit actor (defaults to the scope — every org consumer’s actor name equals its scope).

The serve leg holds one shared child per CuoraSecrets clone group (Arc); clones share the process.

pub fn rref(&self, name: &str) -> String

The cuora ref one secret name resolves to — cuora://<scope>/<name>.

Names are env-var-shaped ([A-Z0-9_]) which cuora’s ref grammar accepts verbatim — no slugging, the name IS the ref tail, so cuora put cuora://<scope>/<NAME> is the migration path with zero translation.
