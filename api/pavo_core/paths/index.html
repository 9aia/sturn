Tamias home resolution — copied from tamias-driver (the helpers are tiny and pavo must not depend on tamias crates; the layout is the shared contract, not the code).

<tamias-home> resolves as $TAMIAS_HOME → $XDG_DATA_HOME/tamias → ~/.local/share/tamias → ./.tamias. Pavo-capable drivers live alongside install drivers in <tamias-home>/drivers/ — one dir, manifest/capabilities disambiguates (P-003 locked decision: no second discovery dir).
