pub fn effective_bindings<'a>(
    sources: impl IntoIterator<Item = BindingSource<'a>>,
    overlay: &BTreeMap<String, String>,

Expand description

Merge declared/suggested bindings with a user-keymap overlay.

overlay maps command id → keys: the value is a comma-separated list of crate::keymap::KeySpecs ("ctrl+p,/"), or a single spec. An overlay entry replaces the declaration’s suggested keys wholesale; command ids absent from the overlay keep their suggestions. Sources producing the same command id dedupe to the first occurrence.

Returns the list sorted by command id — deterministic for help screens and tests.
