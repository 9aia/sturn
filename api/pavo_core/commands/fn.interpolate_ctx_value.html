The JSON-ish interpolation context — what interpolate resolves {a.b} paths against. Built by ResolveContext::interpolate_ctx; hosts interpolating item_route/ActionResult.route should use the same shape.

Keys present (when their source exists):

  • driver — current driver name (string)
  • view — current view id (string)
  • data — the view’s query-binding data map
  • target — the invoke target JSON (verbatim)
  • params — the invoke params map
  • item — the selected TreeItem as JSON (see item_value) — only when the caller supplies one
