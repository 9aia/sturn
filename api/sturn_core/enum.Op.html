Expand description

The op vocabulary. Merge semantics stay git’s — ops carry intent and coordination metadata, not a new merge theory.

Advisory lock on a resource URI — publish before acting. glob carries scheme:path: fs: globs (src/**, and a bare glob means fs:) or opaque resources (dev:display0, net:13000, sess:T-012, cap:role).

Ask

A question awaiting a verdict — pending response in the WAL. The ask id is this event’s own id (the blob sha), the same handle review uses.

Fields

§subject: String

What is being asked.

§target: String

Who may answer — free-form spec: actor:<name>, human:<name>, node:<host>, claim-holder:<glob>, any. Routers and responders filter on it.

§options: Vec<String>

Offered verdicts — advisory, answers are free-form.

§ttl_secs: u64

Seconds until the ask expires. 0 = never.

§

Answer

A verdict closing an ask — first terminal op wins.

Fields

§ask: String

The Ask event id being answered.

§verdict: String
§

Cancel

Withdraw an open ask.

Fields

§ask: String

The Ask event id being withdrawn.
