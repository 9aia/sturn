sturn-core — domain types, sturn.toml config, and the shared vocabulary every port and impl speaks.

The WAL is the state: ops append to refs/sturn/wal/<ws> and the working tree is a projection. Claims are advisory locks published before edits — conflicts get prevented, not discovered at merge.

Config
sturn.toml — one per coordinated repo. Secrets never live here; secret material resolves through the Secrets chain.
Event
One op appended to a workspace WAL — the unit of coordination. Storage is Wal-impl defined (git impl: blob in the ODB, chained by commits on refs/sturn/wal/<ws>); replicated by ordinary push/fetch.

WalCfg
[wal] — where the op log lives inside git refs.

Functions§

overlay
Fold tree-affecting ops into a path→blob overlay (None = deleted). Pass only events since the last snapshot — earlier ones are already in the tip. resolve maps a path to its blob sha in the base tree, needed when a Rename source was never overlaid.
since_last_snapshot
Index just after the last Snapshot marker — ops before it are already inside the ws tip commit.
