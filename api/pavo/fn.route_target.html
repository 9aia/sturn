pub(crate) fn route_target(host: &Host, route: &str) -> Option<(String, Params)>
Expand description

Resolve a /path?query route to a <driver>:<view> ref + view params by matching declared ViewSpec.route/item_route patterns across all discovered manifests. None when nothing matches — callers only invoke this for leading-/ targets.

Query pairs become params via the same scalar rule as --param (http::param_json: JSON when possible, else string) and override {name} path captures on key conflicts.
