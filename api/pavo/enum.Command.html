View

Resolve + render a view — pavo view myco:board or a /myco/item?id=T-1 route.

Fields

§target: String

<driver>:<view> deep link (bare <driver> = its first view) or a /route?query matching a declared view route / item_route template.

§params: Vec<String>

View param, key=value (repeatable). Values parse as JSON when possible, else strings. A view’s filter_param (ViewSpec, convention q) is just another --param.

§format: String

Output format — text (default), json, dot, mermaid, or any format a renderer plugin claims (e.g. svg, ascii; see a driver’s manifest renderers).

Actions

JSON output.

§

Invoke

Invoke an action — pavo invoke myco:board refresh. Dispatches the invoke wire op; --json dumps the full ActionResult.

Fields

§target: String

<driver>:<view> deep link the action lives in (bare <driver> = its first view).

§action: String

Action id — see pavo actions <driver>:<view>.

§params: Vec<String>

Action param, key=value (repeatable) — the action’s ParamSchema names. Values parse as JSON when possible, else strings.

§action_target: Option<String>

Opaque action target — JSON ({"id":"T-1"}) or a bare string. What the action’s target context calls for (selected row, item id, …); the driver interprets it.

§target_id: Option<String>

Shorthand for --target <id> as a plain string — also the type-target confirmation: the id is the typed confirmation, so --yes --target-id T-1 is the non-interactive spelling.

§yes: bool

Skip confirmation prompts. confirm actions require it off-TTY; type-target actions still need --target-id (the id is the confirmation — --yes only skips the interactive “type it” prompt).

§interactive: bool

Prompt on a TTY for each action param not given via --param (uses the ParamSchema: enum lists options, bool y/n, defaults on empty input). Errors off-TTY.

§json: bool

JSON output — dumps the full ActionResult.

<driver>:<view> deep link (bare <driver> = its first view) or a /route?query. Omit to open the TUI dashboard.
