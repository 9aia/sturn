pub fn stream_upstream( &self, id: &str, ) -> Option<(String, Option<String>, String)>

(url, token, upstream path) for the entity’s live event stream — the kind policy’s stream_path (id already percent-encoded) plus its call_params query, resolved against the owning node. None when the entity isn’t projected, its kind is unregistered, or the kind has no stream — the hub’s /api/entities/{id}/stream route answers 404 on None.
