Module cli 

Source
Expand description

Ops manifest → a generated clap CLI (feature cli).

command builds the parser: one subcommand per op (params → args per ParamKind) plus one per entry in surfaces (trailing argv passthrough — unbounded surfaces stream). run parses an argv, builds the wire params map, dispatches through a Surface, prints stdout/stderr, and returns the engine’s exit code.

Every subcommand also accepts --root <dir> — the repo/dir hint wire requests already carry (params.root); drivers that resolve roots from params honor it, others ignore it.

Every op subcommand also accepts --params-stdin — read the op’s params as one JSON object on stdin and merge them over the argv params (stdin wins per key). This is the channel for secret-bearing params (ParamSpec::secret): values never touch argv, shell history, or /proc. Required (arg) params may come from either side; a missing one is a usage error either way.

Build the generated CLI’s clap parser for manifest. bin is the displayed program name (kuda, tamias-driver-cli, …).

Parse argv (argv[0] included) against command, dispatch the matched op/surface through surface, print captured output, and return the exit code. clap errors/help print and exit 2/0 through clap’s own rendering. --params-stdin reads real stdin.
