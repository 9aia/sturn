Item status — the owned state machine.

open        → claimed | in-progress | deferred | cancelled
claimed     → in-progress | open | deferred | cancelled
in-progress → blocked | done | deferred | open | cancelled
blocked     → in-progress | open | deferred | cancelled
deferred    → open | cancelled
done        → open | deferred          (reopen — un-archives)
cancelled   → open | deferred          (same)

done/cancelled are the archive states — the item leaves the live docs for DONE.md — but the archive isn’t a one-way door: a premature done (or a cancelled item worth rescuing) reopens to open or re-parks to deferred. Invalid transitions are typed errors, never panics.
