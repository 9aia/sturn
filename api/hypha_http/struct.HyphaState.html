Expand description

Shared state threaded through every substrate handler — the createApp options object minus everything an integration owns (session planes, meta stores, campaign state). Clone is cheap (Arc/Mutex/registry clones) because axum clones state per request.

Fields§

§kinds: KindRegistry

kind → EntityPlane registry behind /api/entities*. Empty on a bare substrate — integrations register their kinds at composition (Self::with_kind).

§feed: EventFeed

Process-wide event feed behind GET /api/events.

§node: Arc<Mutex<NodeIdentity>>

Identity reported by GET /api/node; PATCH /api/node renames it in place (a mutex because HyphaState clones per request).

§node_path: Option<PathBuf>

Where the identity persists (HYPHA_NODE); None keeps a PATCH /api/node rename in-memory only.

§node_agents: Vec<String>

Agent ids advertised by GET /api/node — the integration’s runtime inventory (empty on a bare substrate; peregrin fills it from its session plane). Static fallback: a live Self::agent_lister wins when installed.

§agent_lister: Option<AgentLister>

Live agent-inventory provider for GET /api/node — see AgentLister. None → node_agents is reported verbatim.

§node_capabilities: Option<Vec<String>>

Full capabilities override for GET /api/node — integrations whose wire contract names its own capability tags (peregrin’s sessions/projects/import) install the exact list; None → the substrate computes entities/events/export plus push/pairing when those backends are wired.

§entity_host: Option<Arc<dyn Any + Send + Sync>>

Opaque payload the EntityContext handed to every EntityPlane carries as host — integrations whose planes wrap host handlers (peregrin’s session plane downcasts it back to AppState) install their own state via Self::with_entity_host. None → the HyphaState itself.

§auth_cookie: Arc<str>

Auth-cookie name the login/logout exchange sets and the gate reads — hypha_token on a bare substrate; integrations keep their historical name (peregrin serves sepia_token).

§pairing: Option<Pairing>

Pairing backend for POST /api/pair + issued-credential auth.

§pair_limit: RateLimiter

Per-client-IP throttle on POST /api/pair — the one route that mints a bearer credential with no prior auth, so it’s the brute- force surface. Keyed by ConnectInfo socket IP (never X-Forwarded-For — the node doesn’t run behind a trusted proxy).

§token: Option<String>

HYPHA_TOKEN — None/empty means bearer auth is off entirely.

§origins: Vec<String>

CORS allowlist — * echoes any Origin back (bearer auth, not CORS, is the gate).

§keep_alive: Duration

SSE keep-alive cadence; 0 disables.

§push: Option<Arc<PushStore>>

Web Push service — None → /api/push/* answers 501.

§health_probe: Option<HealthProbe>

Deep health probe for GET /api/health — integrations with a real liveness check (peregrin’s session-plane probe) install a handler returning the full response; None → the static {"ok":true} liveness answer.

§kv: Option<Arc<dyn KvStore>>

Node-local key/value store behind /api/kv* (P-006) — None → those routes answer 501. Self::from_env opens the JSON-file impl at HYPHA_KV (<home>/kv.json); integrations wanting a different backend or the meta.json migration install their own via Self::with_kv.

§kv_hook: Option<KvHook>

Post-write hook for /api/kv* mutations — see KvHook.
