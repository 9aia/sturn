routes/kv.ts generalized — the substrate KV surface (P-006): /api/kv namespace list, /api/kv/{ns} entry map, and /api/kv/{ns}/{key} single-entry CRUD over [hypha_kv::KvStore], plus POST /api/client/keypair (the stateless Ed25519 mint moved verbatim from peregrin — a client on a non-secure context has no crypto.subtle, so the node mints its identity server-side).

Visibility is the wire gate: internal namespaces answer reads with the same 404 as a missing key and reject writes with 400 — the generic replacement for peregrin’s INTERNAL_CONFIG denylist. The store itself stays agnostic (store-API callers read internal namespaces freely).

Writes report through crate::KvHook: default is a "kv" feed event ({ns, key, value} / {ns, key, deleted}); integrations install a hook to emit their own kinds (peregrin’s "project" events) or suppress entirely.
