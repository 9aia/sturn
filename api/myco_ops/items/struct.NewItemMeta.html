Expand description

Optional metadata applied to a freshly-created item — the parsed --pri/--owner/--label/--blocks/--epic/--milestone/--due/--est/ --cycle bundle every add/new front-end shares. Validated on apply.

impl NewItemMeta

Source

pub fn apply(&self, item: &mut Item) -> Result<(), String>

Apply the metadata to item — labels and group names are validated (invalid tokens can’t be emitted by the file grammar). All-or-nothing: everything validates before any field moves, so a bad --epic can’t leave labels applied.
