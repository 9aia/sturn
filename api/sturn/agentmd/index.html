Module agentmd 

Source
Expand description

The managed AGENTS.md agent-awareness block — init writes it so every sturn-wired repo carries the same operating rules.

The block is marker-delimited so human prose elsewhere in the file survives syncs; a stale or hand-written Sturn awareness section is upgraded in place, everything else is untouched.
