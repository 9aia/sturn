Advisory lock on a resource URI — published before edits.

Seconds the claim lives (auto-expiry, no zombie locks).

Claims

§

Check

List live claims conflicting with a URI — consult before acting on a resource. Exits 1 when the URI is contested.

Fields

§uri: String

Resource URI or path glob — same form claim takes.

§fence: Option<u64>

Staleness probe: report only conflicting claims with a fencing token above N — pass the fence claim printed to ask “has my claim been superseded?”.

§watch: bool

Keep watching — stream conflict-set changes via WAL poll. Works daemon-free; combines with –fence.

§

Ask

Open a pending-response ask — the printed event id is the ask handle that answer/cancel/wait take.

Fields

§subject: String

What is being asked.

§ws: String

Workspace asking.

§target: String

Who may answer — free-form spec: actor:<name>, human:<name>, node:<host>, claim-holder:<glob>, any.

§options: Vec<String>

Offered verdict — repeatable, advisory only.

§ttl: u64

Seconds until the ask expires. 0 = never.

§

Asks

Pending asks across every workspace — open by default.

Fields

§all: bool

Include resolved asks (answered/cancelled/expired).

§json: bool

Emit a JSON array instead of text lines.

§

§ws: String

§

Cancel

Withdraw an open ask.

Fields

§ask: String

Ask event id.

§ws: String
§

Wait

Block until an ask resolves — prints the result as JSON. Exit: 0 answered, 2 cancelled, 3 expired, 4 timeout.

Fields

§ask: String

Ask event id.

§timeout: u64

Max seconds to wait. 0 = until resolved.

§poll: u64

Poll interval, ms.

§

Bridge

Bridge snapshot events to a bupha webhook — GitHub-shaped, HMAC-signed. Bupha runs CI on snaps with zero bupha changes.

Fields

§to: String

bupha listener URL (e.g. http://127.0.0.1:29173/).

§secret_env: String

Env var naming the webhook secret (HMAC-SHA256).

§

Mcp

MCP stdio server — the 9-tool agent surface on JSON-RPC. –ws makes it the agent’s ws: presence ops emit on connect.

Fields

§ws: Option<String>
§

Exec

Hydrate a ws to tmpfs and run a command inside — compilers need POSIX; agents don’t. Exits with the command’s status.

Fields

Workspace to hydrate.

§keep: bool

Keep the hydrated dir after exit.

§writeback: bool

Write filesystem edits back as ops on the ws.

§cmd: Vec<String>

Command + args, after --.
