sturn — evented coordination over the git object store.

The WAL is the state; the tree is a projection; the bus is a cache. Composition root: wires ports (wal/bus/ws/vcs/config/ service) to impls (git plumbing, redb, toml, systemd).

diff_tick 🔒
One diff pass over scope (None = ws namespaces ∪ WAL refs): for each workspace whose WAL head moved since heads, emit the new events. An empty cursor means the ws log replays whole — sliced to post-snapshot so both a fresh diff and a ws born mid-stream show only in-flight ops. Errors degrade to silence, matching daemon_tick — the WAL stays the authority.
