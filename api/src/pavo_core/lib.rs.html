1//! pavo-core — host core: tamias driver discovery, contribution merge,
2//! per-driver wire clients, ViewNode IR helpers, and the view-model
3//! cache.
4//!
5//! The host's job (per P-003): find `tamias-driver-*` executables that
6//! speak pavo (a `manifest` verb answering [`pavo_protocol::DriverManifest`],
7//! or `capabilities` advertising it), merge their `contributes` slots
8//! into one chrome description, and resolve `<driver>:<view>` deep
9//! links into [`pavo_protocol::wire::ViewResult`]s by speaking the ndjson
10//! wire (`{"op":"…"}` → `{"ok":…}`) over each driver's `serve` verb.
11//!
12//! Everything here is sync and std-only — no async runtime, no
13//! renderer deps. Renderers (CLI/TUI/web) consume [`Host`]'s output;
14//! they never see driver processes.
15//!
16//! Module map:
17//!
18//! - [`discovery`] — scan `PATH` + `<tamias-home>/drivers/` for
19//!   pavo-capable `tamias-driver-*` executables.
20//! - [`client`] — [`client::DriverClient`], one spawned `serve`
21//!   process per driver, request/response with timeout + one restart.
22//! - [`merge`] — fold every driver's `contributes` into a single
23//!   [`merge::Chrome`] (navbar/dashboard/statusbar/routes/sidebar/
24//!   headerActions/notifications/jobs + `extra`).
25//! - [`deps`] — topological ordering over `DriverManifest.deps`
26//!   (`requires`/`optional`); [`host::Host`] keeps drivers in dep
27//!   order and quarantines offenders.
28//! - [`host`] — [`host::Host`], the composition root renderers use:
29//!   discovery → manifests → clients → views/routes/chrome.
30//! - [`viewnode`] — walk/evaluate helpers over the ViewNode IR
31//!   (`find_nodes`, `collect_queries`, KV degradation).
32//! - [`renderers`] — renderer-plugin registry: manifest `renderers[]`
33//!   declarations → kind claims, conflict resolution, `render` ops.
34//! - [`commands`] — the unified command layer: the
35//!   `action:`/`route:`/`host.`/`driver:` grammar, route-template
36//!   interpolation, host builtins, and effective keybindings.
37//! - [`keymap`] — [`keymap::KeySpec`], the shared keybinding-spec
38//!   grammar hosts validate/normalize against.
39//! - [`paths`] — `<tamias-home>` resolution (`$TAMIAS_HOME` →
40//!   `$XDG_DATA_HOME/tamias` → `~/.local/share/tamias` → `./.tamias`).
41//! - [`cache`] — small TTL cache for view models.
42//! - [`error`] — the crate's [`error::PavoError`] type.
43
