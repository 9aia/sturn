hypha-kv-file — the JSON-file [KvStore] impl, porting sepia_meta::MetaStore’s persistence mechanics: one document, rewritten atomically (tmp + rename) after every mutation, and a corrupt or half-written file degrades to empty rather than failing.

On-disk shape:

{
  "namespaces": {
    "config": { "visibility": "public", "entries": { "theme": "dark" } },
    "push":   { "visibility": "internal", "entries": { "vapid": {} } }
  }
}

Reads are tolerant in both directions: a top-level object without a namespaces key is read as the flat {ns: {key: value}} shape (every top-level object value becomes a public namespace’s entries), which is the shape a migrated meta.json config/ projects section already has. Writes always emit the canonical namespaces form.
